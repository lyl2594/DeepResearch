⚙️ 配置指南（下载后如何使用）

本系统通过 .env 与 conf.yaml 完成配置。点击标签查看；克隆仓库后复制示例文件并填写即可运行。

# ========== LLM 配置（OpenAI 兼容）==========
# 环境变量会覆盖 conf.yaml 里的同名字段（BASIC_MODEL__<key> 格式）
BASIC_MODEL__base_url=http://your-llm-host:port/v1
BASIC_MODEL__model=Qwen3-32B-FP8
BASIC_MODEL__api_key=YOUR_API_KEY
BASIC_MODEL__token_limit=32768      # 上下文上限（缺省则上下文管理失效）

# ========== 搜索引擎 ==========
SEARCH_API=duckduckgo               # duckduckgo / none

# ========== 开关 ==========
DEBUG=True
ENABLE_PYTHON_REPL=true             # Coder Agent 的 Python REPL
ENABLE_MCP_SERVER_CONFIGURATION=false  # MCP 动态工具（默认关闭）

# ========== PostgreSQL（业务库 + checkpoint 共用）==========
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/postgres
CHECKPOINT_DB_URL=postgresql://postgres:postgres@localhost:5432/postgres

# ========== AIHUB 知识库（实战可选，凭据勿提交真实值）==========
AIHUB_API_URL=""
AIHUB_USERNAME=""
AIHUB_PASSWORD=""

配置优先级：环境变量 BASIC_MODEL__<key> > conf.yaml > 内置默认值。复制 cp .env.example .env 后按需修改。

# 复制为 conf.yaml 后使用（优先级低于环境变量，二选一即可）
BASIC_MODEL:
  base_url: http://your-llm-host:port/v1
  model: Qwen3-32B-FP8
  api_key: "your-api-key"
  token_limit: 32768        # ContextManager 需要
  max_retries: 3

# Rerank 重排模型（AIHUB 知识库增强检索用）
RERANK_MODEL:
  type: "emb"
  base_url: "http://your-embedding-host:port/api/emb/embedding"
  model: ""
  api_key: ""
  top_n: 6
# 前端 web/.env（由 web/.env.example 复制而来）
NEXT_PUBLIC_API_URL=http://localhost:8000/api   # 后端 API 代理目标
GITHUB_OAUTH_TOKEN=                            # 教学版留空
步骤命令说明
克隆git clone <repo> && cd mini-deepresearch下载代码
复制配置cp .env.example .env && cp conf.example.yaml conf.yaml生成本地配置
填 LLM编辑 .env 的 base_url / model / api_key指向 OpenAI 兼容模型服务
启动后端uv run server.py自动建 venv + 装依赖；默认 8000 端口
启动前端cd web && pnpm install && pnpm dev访问 http://localhost:3000
